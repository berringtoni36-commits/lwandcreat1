# 本次暂停提交的数据边界

本次 GitHub 上传是**代码和续做计划检查点**，不是包含全部原始数组的正式复现包。`experiments_v12`–`experiments_v14` 新生成的 `.npz` 与 `.mat` 数值文件共约 9.4 GiB，留在当前工作机；没有删除。`experiments_v14/outputs/n14_select_*` 的九条完整及四条中断现场也只在本机，避免把缺少配套二进制轨迹的小型 JSON 单独上传后误认为可直接分析。

Git 中保存生成器、冻结协议及 SHA、控制器、计数内核、Python/MATLAB 复核脚本、测试、开发/审计摘要、查新和论文方法草稿。新机器可用这些文件、相同数值环境及固定的 SeedSequence 命名空间重新生成 E2/E3 选择输入，并按[暂停续做说明](PAUSE_AND_RESUME.md)重跑 16 份选择运行。正式选择分析要求每份结果的原始轨迹、元数据及哈希齐全；只靠本仓库的开发 JSON 或暂停状态报告**不能**得出选择或确认结论。

若在同一机器恢复，保留的本机结果可按原冻结模型续跑 7 份未完成运行，不覆盖已有成功的九份；已经中断的尝试日志仍保留。以后若要把全部原始数组作为可下载的复现包，应在正式确认和论文结论稳定后，单独选择有足够容量的 Git LFS 或数据仓库存放、验证上传链路并记录校验和。当前提交不声称这些数据已上传。
