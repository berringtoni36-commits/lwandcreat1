## 主要修改

### 结构与期刊要素

3. **关键词**："Kronecker decomposition" 改为 "Kronecker product decomposition"，"normalized adaptive filtering" 改为 "filtered-x normalized least mean square"。
4. **新增声明**：生成式 AI 使用声明占位（Elsevier 的要求），措辞用的是 Elsevier 的标准模板，需要你填写。

### 引言（重写）
原引言基本是在罗列文献，没有讲清楚“为什么要对 RFF 系数做 Kronecker 结构”。新的引言分 4 段：
1. **背景**：ANC 为什么需要非线性控制器。
2. **RFF 控制器的问题**：要逼近得准需要 D 很大，于是要在线自适应的系数就很多，而归一化梯度类更新的收敛时间随系数个数增加。
3. **鲁棒性**：MCC 相关工作，包括 Signal Processing 上的 [ref6–ref9]。
4. **KPD 与研究空白**：已有 KPD 工作都作用在线性滤波器或多项式的抽头上，这些系数本身有时间结构；RFF 系数没有这种结构。这里**主动回应了审稿人最可能问的问题**：本文把因子分解当作一种“自适应结构”，而不是系数的物理模型，并指向 4.4 节的理论解释。

### 方法与理论
1. **新增符号说明段**（Notation）。
2. **2.1 节补充**：说明式 (3)(4) 是非线性 ANC 的常用基准，出自 Tan & Jiang 2001 和 Das & Panda 2004（待核实）。你代码里的非最小相位次级通道 [0 0 1 1.5 −1] 也和这个基准一致。
3. **2.3 节**：式 (9) 里的 e_n 原来没有定义，已补上。
4. **3.2 节新增残差可实现性说明**：d(n) 本身测不到，但 d(n)+v(n) = e(n)+y_s(n) 可以由实测误差加次级通道模型输出重构，也就是 modified FxLMS 结构。这样式 (15) 在真实系统里就能实现，堵住了审稿人质疑“用了测不到的信号”的口子。
5. **新增 4.4 节：等价预条件更新与步长范围**（这是本次最主要的理论补充）：
   - 证明因子递推在一阶近似下等价于对完整系数向量做一次**带正半定预条件矩阵 P_n 的 filtered-x 更新**（新式 eq:precond、eq:Pmat）。这给“为什么结构化能加快收敛”提供了机理解释，原稿 4.4 节只有定性描述。
   - 由后验残差（eq:post）推出步长条件 **0 < μa+μb < 2**（eq:stepcond），与 NLMS 的 0<μ<2 对应。
   - 推导我逐步核对过：用了 vec(XYZ)=(Zᵀ⊗X)vec(Y)，qᵀPq = μbρb+μaρa 与式 (13) 一致。

### 实验部分
1. **5.1 节重写**实验设置，补充 α 稳定噪声生成方法的出处（Chambers–Mallows–Stuck 1976）。
2. **5.2 节**：补充了“对比实验为什么用 σc=2”的解释：两种控制器用同一个未调过的核宽，差异才能归因于系数结构。
3. **5.3 / 5.5 节加入有效步长说明**：按新推出的步长条件，混沌和脉冲实验里结构化控制器的有效步长是 μa+μb=0.16，大于基线的 μ=0.05；高斯实验里是 0.24，小于基线的 0.30。我把这一点如实写进去了，并用高斯结果说明“收敛快不是因为步长大”。审稿人看表 3 自己也能算出来，主动说明比被质问好。
4. **5.6 节**：总结里加了定量结论：乘法增加 22%，任何条件下后期衰减的损失都不超过 0.2 dB（脉冲实验里 −4.7 vs −4.9 dB）。
5. **表 4**：首列改为 Chaotic / Impulsive / Gaussian，解决超宽 21 pt 的问题，数据不变。
6. **图 5–7 图注**：加了阈值虚线的说明，要等图重画之后才对得上。

1. **基线用的是哪种残差？** 修改稿写的是 RFF-MCC 也用冻结系数残差 d(n) − wᵀq + v(n)。如果基线仿真用的是物理误差 e(n)，而 NKP 用的是冻结残差，那两者的对比条件不一样，正文必须改写。
2. **k 扫描（图 3、图 4）用的是什么步长和设置？** 代码文件夹里的 `FIG5_sweepK_NKP_RFFxMCC_Logistic.m` 用的是 μ=0.8、gamma_rff=1.0（相当于 ℓr=1，而不是正文的 3.9）、最后 5000 点求稳态。请确认图 3、图 4 是否由这组设置得到，我再把数值填进正文（目前是占位符）。
