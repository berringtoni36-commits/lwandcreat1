# 在线自适应 Kronecker 项数：独立开发版本

本目录在 `experiments_v10/anc_core.py` 的顺序因子更新外增加在线模型选择。旧稿、旧代码和旧实验结果均不覆盖。当前为算法开发和小规模验证，不是已经验证优越性的投稿版本。

已有运行的用途和报告见 [`outputs/README.md`](outputs/README.md)；新增实验的记录格式见[新增实验指南](../docs/新增实验指南.md)。

## 运行

在本目录使用带 NumPy 的 Python：

```powershell
python -B test_adaptive.py
python -B run_adaptive.py --profile smoke
python -B run_adaptive.py --profile pilot
python -B analyze_adaptive.py outputs/某次运行目录
```

- `smoke`：3 个工况，每工况 1 次，每次 8000 点，验证流程。
- `pilot`：3 个工况，每工况默认 3 次；固定混沌 20000 点、高斯参考加稳定分布测量噪声 20000 点、分段非线性 32000 点。`--runs N` 可覆盖次数。
- 绘图依赖 Matplotlib，依赖版本见仓库根目录 `requirements.txt`。分析脚本也支持此前本机放在 `.deps/` 的绘图依赖；该目录不纳入版本管理。
- 每次创建独立时间戳输出目录。`protocol.json` 在运行前保存参数和软件版本；`sources/` 保存该次实际使用的代码快照。
- 输入 x、扰动 d、噪声 v、RFF 频率/相位以及初始化因子都保存在逐次 NPZ 中，避免仅保存种子而无法跨环境重放混沌信号。

## 已实现的方法

模型为 `w = vec(B A^T)`，主体项数 R 随时间改变。每次 Monte Carlo 运行有自己的控制器和选择状态，不对多个运行的损失求平均来做在线决策。

1. 固定结构阶段直接调用 v10 的 `KronRFF.step`：先更新 B，再用更新后的 B 重新计算 A 的回归量和残差。
2. 预热后，增长/剪枝候选交替提出。边界 R=1 只能增长，R=8 只能剪枝，每次只测试一个候选。
3. 增长复制当前模型，附加一个 A 非零、B 为零的新项。新 A 的范数匹配现有 A 列的均方根范数，避免已训练的大因子压制新项在联合归一化中的更新；零 B 保证候选的初始输出与原模型完全相同。
4. 剪枝用间隔采样的留一项预测损失进行筛选，然后复制当前模型并删除被选列。该筛选值只是代理指标，不当作物理降噪损失。
5. 候选先训练，再在新的时间窗口中与当前模型一起进行在线验证。两者共享输入、RFF 和滤波特征，但各自维护因子和输出 FIR 历史。
6. 每个验证采样点用更新前产生的输出计算物理残差并记分，然后允许因子更新。当前代码的 `step` 虽在返回前执行更新，返回的次级通道输出仍来自本采样更新前的控制输出。
7. 仅当候选的惩罚目标比当前模型至少低 margin 时接受，否则丢弃。
8. 接受后，两个控制器的原始输出在 ramp_samples 内线性过渡。真实输出缓冲连续保留，先混合原始输出，再经过次级通道。不能直接按当前门控混合两套已滤波输出。
9. 切换完成后丢弃旧分支，进入冷却期；拒绝候选也进入冷却期。

第一版是周期性候选比较，没有叠加平台期触发、神经网络、自动阈值调整、回滚等额外机制。这样可以明确分离因子更新、结构选择和切换的作用。

## 两种误差的边界

- 因子更新：`epsilon = d + v - w^T q`，与当前论文一致。
- 候选验证与 ANR：`e_j = d + v - S * y_j`，其中 `y_j` 是该分支自己的历时输出。
- 实际执行器：`e_actual = d + v - S * y_actual`，始终使用真实混合输出的连续历史。
- 当前模拟采用准确的次级通道模型，直接给各分支传入 d+v；部署时对应 `e_measured + S_hat * y_actual`。这不是已经完成的通道失配或硬件验证。

## 统一选择目标

损失 `rho(e) = 1 - exp(-e^2 / (2 sigma^2))`，采用无量纲有界定义。

在同一未来验证窗口内：

`J_j = mean(rho(e_j)) + lambda_cost * C(R_j) / C_ref`。

接受条件：`J_candidate < J_current - margin`。

增长和剪枝使用同一个判据。这里的未来是“候选建立以后实际到达的数据”，实现中没有读取尚未发生的采样点。验证期间仍在线更新，不声称样本独立，不做基于独立样本假定的在线显著性检验。

默认：R0=2、Rmin=1、Rmax=8；预热 2000 点、候选训练 1000 点、验证 1000 点、过渡 100 点、冷却 2000 点；每 50 点筛选一次，筛选平滑系数 0.9；lambda_cost=0.01、margin=0.0005。

这些是开发起始值，不是经过搜索的最优参数。MCC 有界不等于能保证拒绝每一次脉冲误触发。

## 成本与内存

沿用当前稿件的主体乘法口径：

`C(R) = DM + DLs + D + 3RD + R D2 + 3R(D1+D2) + 8`。

当 M=20、D=500、D1=25、D2=20、Ls=4：`C(R)=12508+1655R`。

- R=2：15818；R=4：19128；R=8：25748。
- 完整 RFF-MCC：14504。
- 以上旧公式未计输出 FIR，在本次成本账本中另计，每条输出 FIR 收费 Ls 次，含零系数，保持统一口径。
- 共享特征生成与特征滤波成本 `D(M+1+Ls)=12500` 每个采样点仅计一次。
- 候选活动期间另计 `C(R_candidate)-12500`、它自己的输出 FIR、验证损失和切换开销。
- 另计实际执行器输出 FIR、留一筛选矩阵乘积/内积/损失/平滑，以及新 A 因子的缩放乘法。
- 指数函数次数另列；除法、平方根、随机数生成、数组复制、内存分配、比较和加法不伪装成乘法。
- 这是与正文一致的理论乘法账本，不是硬件指令计数。逐控制器 Python 调用耗时另外报告，排除共同的特征生成。

J 中使用未来单个控制器的主体成本进行选择；最终报告必须加上真实发生的搜索和切换开销。因此，J 降低不保证包含候选开销的总运算量降低。

`R` 只表示主体结构。过渡期间两个分支都计算；`candidate_R`、`live_terms`、`gamma` 记录这部分活动。`resident_factor_coeffs` 包括主体和候选因子，不能用平均主体参数数代替峰值内存。该字段只统计因子，不包含固定映射、输出缓冲和所有 Python 对象。

## 验证与解释

`test_adaptive.py` 检查：关闭选择后与 v10 逐位相同；新项零输出和可学习性；新项尺度；精确删项；过渡时的物理 FIR 连续性；验证用物理预更新误差；惩罚与滞回；共享计算/候选成本；确定性与项数边界；训练—验证时间分离。

运行器还逐次检查 `S * 实际混合输出 == 记录的实际次级通道输出`，并检查所有 ANR 和误差为有限数。

试运行比较固定 R=1/2/4/8、完整 500 维 RFF-MCC 与动态版本。同一次运行共享输入、映射和初始因子前缀。动态版本从固定 R=2 的同一状态开始。

分段工况只改变非线性系数，并插入一次短脉冲。没有指定“应当”出现的项数轨迹，也不对各段使用未来 RMS 进行等幅归一化。该工况的输出幅度和模型难度可能同时变化，应据此限制解释。

## 如何接入论文

先作为独立方法草案，不把固定 R 数据改名成动态实验。

- 第 3 节之后增加在线项数选择小节，定义候选、物理验证目标和切换流程。
- 原有后验残差不增命题继续限定在结构固定、正常因子更新的阶段；结构切换和物理闭环没有新增稳定性证明。
- 成本表同时列主体、候选评估与总成本，区分平均活动参数和峰值驻留因子。
- 原 R 扫描与主实验保留为固定结构基线；动态轨迹及效果只能引用本目录新数据。
- 在结果得到支持前，不写“自动达到最优秩”“保证降低总复杂度”“保证不受脉冲误触发”。

相关方法区别仍需查证，尤其是已有变阶长 MCC 和非线性 Kronecker 滤波；本目录不宣称已完成新颖性检索或获得新的理论保证。
