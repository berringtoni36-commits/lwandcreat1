# E1 双向容量与因果排列的开发集诊断

**结论：E1 的原始 RFF 顺序确有低→高→低的容量差异，但用第一低段当前权重得到一次带符号排序并固定三段，不能支持实际的 R2→R4→R2。** 给定已知段界，第二段逆排回原 RFF 顺序后 R4 能恢复；第三段再按当前高段权重排序并剪为 R2，即使延迟 20k 或 50k 点，段末物理 ANR 仍明显低于原顺序固定控制器。这是开发集反事实，不是在线结构门控的成功证据。

## 来源与设计

唯一输入是 `experiments_v12/outputs/mechanism_dev_residual_only` 保存的 E1 run00–04；其 `protocol.json` 明确为 `phase=dev`、种子 `2026092801`，每条 300,000 点。未使用历史 `selection_e1_v500`，也未读取新的 select/confirm。归档生成源码中，真实教师在原 500 维 RFF 顺序的 (20\times25) 网格上按三段使用

\[
W_{\rm low}=10u_1v_1^\mathsf T\quad(R=1),\qquad
W_{\rm high}=5UV^\mathsf T\quad(R=4),\qquad
W_{\rm low}\quad(R=1).
\]

本诊断从保存的 `x,d,v,Om,ph,initial_A,initial_B` 逐样本重新计算 500 维稠密 RFF、filtered-x 特征、顺序 MCC、实际次级 FIR 与平滑绝对幅值 ANR。物理 ANR 按每段末 5,000 点平均；越负越好。真教师权重只用于重建 `d` 与事后谱诊断，**不用于排列或控制器初始化**。

第一低段的样本 19,999 更新后，连续原顺序 R4 当前系数的 500 个带符号值作稳定升序排列 `p_low`。此排序只依赖当时状态；从样本 20,000 起，两条活动臂均继承 R4 的实际 FIR 与 ANR 历史，并在相同 `z[p_low],q[p_low]` 上各自按最佳 Frobenius SVD 初始化 R2/R4，之后独立顺序更新。排列在三个段固定。比较臂包括原顺序固定 R1/R2/R4，以及以下预定的边界上限：

- **固定排列日程**：前低段排序 R2；100k 在同一排列增加两项（新增 A 随机小幅、B 为零，保证切换瞬间权重不变）；200k 对当前排序 R4 作 SVD 剪为 R2。只用已知段界，不看未来系数。
- **段界重排**：100k 将活动 R2 权重逆排列回原 RFF 顺序，再最佳 R4 截断并续训；200k 将当前 R4 权重重新带符号排序，再最佳 R2 截断并续训。另预定 220k、250k 剪枝，分别让 R4 先看到末低段的 20k、50k 点。每次保持实际 FIR 和 ANR 平滑状态。段界及延迟均是离线给定，不能当在线触发规则。

## 五条开发流的物理 ANR

下表是五条 run 的逐段末窗均值，单位 dB；原始逐 run、逐段结果见 [`segment_results.csv`](segment_results.csv)、[`realign_results.csv`](realign_results.csv)、[`delayed_prune_results.csv`](delayed_prune_results.csv)。三段真实教师秩依次为 1、4、1。

| 控制臂 | 低段1 | 高段2 | 低段3 |
|---|---:|---:|---:|
| 原顺序固定 R1 | -32.875 | -4.192 | -32.868 |
| 原顺序固定 R2 | -32.875 | -7.160 | -32.841 |
| 原顺序固定 R4 | -32.840 | -32.884 | -32.771 |
| 一次固定排序 R2 | -28.149 | -5.986 | -27.465 |
| 一次固定排序 R4 | -31.583 | -8.943 | -29.726 |
| 固定排序 R2→R4→R2（已知段界） | -28.149 | -9.079 | -28.172 |
| 高段逆排原顺序，200k 再排序剪 R2 | -28.149 | **-32.886** | -6.719 |
| 高段同上，220k 再排序剪 R2 | -28.149 | **-32.886** | -26.404 |
| 高段同上，250k 再排序剪 R2 | -28.149 | **-32.886** | -28.051 |

预定 run00 的三段末窗可以直接复核负面转折：原顺序 R4 为 `[-33.373,-33.033,-33.307]`；一次固定排序 R2 为 `[-28.667,-6.590,-27.713]`，一次固定排序 R4 为 `[-32.457,-8.994,-29.904]`。固定排序的 R2→R4→R2 在高段为 `-9.603`。高段逆排原顺序后为 `-33.031`，几乎回到原 R4 的 `-33.033`；而末低段 200k/220k/250k 再排序剪 R2 分别为 `-7.266/-26.610/-28.081`，原 R4 是 `-33.307`。

原顺序中 R1/R2 在两个低段与 R4 很接近，高段则比 R4 分别差约 28.7/25.7 dB；因此**生成的 E1 案例本身**确有低、高、低容量差异。但排序后的 R2 在第一低段已比原顺序 R2 差 4.7 dB，不能称为一个无损的低成本起点；固定排序 R4 在高段比原顺序 R4 差 23.9 dB。高段通过逆排与 R4 续训恢复后，末低段的当下排序剪枝仍不能恢复到原顺序的低秩表现。五条 run 中，高段重排 R4 对连续原顺序 R4 的差值为 `[+0.002,-0.006,+0.001,-0.001,-0.006]` dB，恢复不是单次偶然值。

## 为什么固定或立即重排会失效

排列本身保持 500 维 full 权重的输出不变；改变的是该向量重新变为 (20\times25) 矩阵后的低秩性。第一低段 R4 当前权重形成的排序使**真实低秩 1 教师**在新网格数值秩 20，最佳 R2 相对 Frobenius 谱尾均值 `0.0501`（范围 `0.0291–0.0742`）。真实高秩 4 教师在同一新网格亦为秩 20，最佳 R4 谱尾 `0.6346`（范围 `0.6203–0.6445`），最佳 R2 谱尾 `0.7675`。故高段单靠在这一固定坐标上把 R2 增为 R4，在表示层就受阻；物理高段结果与之吻合。高段逆排回原 RFF 网格后，活动 R2 权重作 R4 截断的误差范围仅 `0.0184–0.0518`，随后 100k 点在线更新可恢复原 R4 高段末窗。

200k 立即从高段 R4 权重排序并 SVD 到 R2 时，**当前权重本身**的截断谱尾均值仅 `0.0328`，看似剪枝便宜；但未来低段的真实教师在这个排序网格中的最佳 R2 谱尾却高达 `0.7285`。这解释了末低段 `-6.719` dB：低段尚未写入当前高段权重，按高段权重取得的排列对新教师不合适。等 R4 看过低段新数据后，真实低教师在当前排序网格的最佳 R2 谱尾降为 220k 的 `0.0742`、250k 的 `0.0493`；对应末窗改善到 `-26.404/-28.051` dB，但仍分别比连续原顺序 R4 差 `6.367/4.720` dB，且 250k 日程已有半个末低段在 R4 成本下运行。谱尾只是静态最佳逼近，不能代替物理 ANR 或在线训练收敛。

## 乘法及存储账本

沿归档 v10 核心的完整主体计数，实际次级 FIR `LS=4` 另计：

\[
C_R=DM+D+DLS+3RD+RD_2+3R(D_1+D_2)+8+LS,
\quad (D,D_1,D_2,M)=(500,25,20,20).
\]

因此每点固定 R1/R2/R4 为 `14,167/15,822/19,132` 次乘法。第一低段排序臂先跑 20k 点 R4，再跑 80k 点 R2，所以其第一段主体均值 `16,484`。下表将 300k 点平均主体成本与计入的一次转换乘法分列；SVD 每次按旧诊断统一取 **100 万乘 convention**，不是精确实测 FLOP。

| 臂 | 平均主体乘/点 | 计入的一次转换乘法 | 说明 |
|---|---:|---:|---|
| 原顺序固定 R1/R2/R4 | 14,167 / 15,822 / 19,132 | 0 | 三个固定基准 |
| 一次排序 R2 | 16,042.7 | 1,002,090 | 20k R4 前缀 + 一次 SVD R2 |
| 一次排序 R4 | 19,132.0 | 1,002,180 | 同样主体秩 4 |
| 固定排序段界 R2→R4→R2 | 17,146.0 | 2,004,230 | 两次 SVD，增项时 50 次随机因子缩放 |
| 高段逆排原顺序，200k 再排序 R2 | 17,146.0 | 3,005,360 | 三次 SVD |
| 同上，220k 再排序 R2 | 17,366.7 | 3,005,360 | 末低段先跑 20k R4 |
| 同上，250k 再排序 R2 | 17,697.7 | 3,005,360 | 末低段先跑 50k R4 |

一次账本还含现有因子形成 500 元权重及 SVD 因子缩放；详细逐臂分段成本见各 JSON。保存一张 500 元排列 `uint16` 表约 **1,000 字节**，若同时保存首低段和末低段的两张表约 2,000 字节（32 位索引分别加倍）。未计排序比较/搬移、每点 `z/q` 的 500 元 gather、随机数生成、状态复制、边界识别、候选并行训练与门控验证；因此这些主体数不能当作已实现的在线总成本。两个已知段界和延迟时间来自离线案例设计，不能据此选择部署时刻。

## 复现与校验

从仓库根目录，使用带 NumPy 的 Python 执行：

```powershell
python -B experiments_v13/diagnostics/e1_permutation_capacity/e1_capacity.py --runs 0
python -B experiments_v13/diagnostics/e1_permutation_capacity/e1_capacity.py
python -B experiments_v13/diagnostics/e1_permutation_capacity/boundary_realign.py
python -B experiments_v13/diagnostics/e1_permutation_capacity/delayed_prune.py --runs 0
python -B experiments_v13/diagnostics/e1_permutation_capacity/delayed_prune.py
python -B experiments_v13/diagnostics/e1_permutation_capacity/verify_outputs.py
python -B experiments_v13/diagnostics/e1_permutation_capacity/summarize_results.py
```

`e1_capacity.py` 与 `delayed_prune.py` 可用 `--refresh` 强制重跑；`boundary_realign.py` 每次逐样本重算。校验脚本核对 `phase=dev`、归档源码散列、输入及初始化散列、教师和 SVD 重构、全部五次 run 的物理重放。原顺序基线对保存结果的最大末窗偏差为 `3.79e-6` dB，真实教师产生的 `d` 重构最大误差 `9.44e-16`，排列输出不变最大误差 `3.06e-16`，保存的 SVD 误差差值为零。所有产出均写在本目录，未改主算法或其他实验目录。

这些结果界定的是**表示与已知时刻转换的上限**。即使段界重排能在高段恢复 R4，这也没有提供可观测、可付费、可验证的在线增项/剪枝判据；末低段的延迟剪枝仍有显著物理差距。不能以教师标签或已知边界把它描述成已实现的双向自适应项数收益。
