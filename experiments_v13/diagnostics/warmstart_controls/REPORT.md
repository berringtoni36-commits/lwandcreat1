# 20k 排序压缩机制对照（仅开发数据）

## 问题与预定对照

在原始、稠密、500 维 RFF 映射上，固定 R4 从相同初值运行到全程样本 19,999 更新完毕；只以此刻的 R4 系数作**带符号升序排序**，从样本 20,000 起切换。E2、E3 的 run00–04 均来自 `experiments_v12/outputs/main_dev_round1` 保存的 **dev** 输入及初值；未读取 select/confirm。四段各 100,000 点，段末 5,000 点取物理 ANR 均值；另外单独重放切换后前 5,000 点，每 500 点记一窗。所有分支继承切换前实际次级 FIR 输出历史和 ANR 平滑状态，使用同一 `x,d,v,Om,ph`，后续逐样本顺序 MCC 更新。

| 代号 | 切换操作 | 用途 |
|---|---|---|
| R4 | 不切换，连续固定 R4 | 同输入基线 |
| A | 排序后 SVD 截断 R2，继续更新 | 待解释机制 |
| B | **同一排序**，独立随机小幅 R2 初值，继续更新 | 拆出 SVD 权重注入的作用；仍使用 R4 确定排序 |
| C | 同一排序，SVD 截断 R4，继续更新 | 较高容量、同坐标参照 |
| D | 恒等顺序，R4 当前权重 SVD 截断 R2，继续更新 | 相同教师权重/截断秩下的排序对照 |
| F | 与 A 相同的排序及 SVD R2，切换后冻结因子 | 后续在线学习对照 |

排序在切换前没有观察未来终点系数或未来数据，但时点 20k 是本诊断预定的。B 不是无教师算法：其排列仍来自已经运行 20k 点的 R4。这里没有构造部署用的在线判据。

## 矩阵、重构与成本

R4 权重先组成 (W=B A^\mathsf{T}\in\mathbb{R}^{20\times25})，按原 RFF 线性顺序展开为 500 元，再用该权重的**带符号数值**稳定排序。各分支同时相同地排列实际 `z` 与 filtered-x 特征 `q`。排序矩阵重新成形为 (20\times25)，做最佳 Frobenius SVD 截断，因子大小为 (A:25\times R,\ B:20\times R)。五次 run 的相对重构误差范围：E2 排序 R2 0.032837–0.091018、排序 R4 0.005618–0.007369、恒等 R2 0.572636–0.641360；E3 分别为 0.035692–0.085463、0.004187–0.007454、0.449551–0.606617。随机 B 初始相对重构误差约 1.0。排序后矩阵数值秩均为 20，**R4 不能精确表示**这一重排的 full500 权重；C 是近似截断，而非精确重参数化。

乘法账本沿用保存的 v10 核心 `mults_kron`，加实际次级 FIR 的 `LS=4`。对 (D=500,D_1=25,D_2=20,M=20)：

\[
C_R=DM+D+DLS+3RD+RD_2+3R(D_1+D_2)+8+LS,
\quad C_4=19132,\ C_2=15822.
\]

R4 前缀占 20k/400k=5%，之后 R2 占 95%；主体平均为 (0.05C_4+0.95C_2=15987.5) 乘/点，较连续 R4 的主体账本低 16.44%。冻结 F 不计算 filtered-x/因子更新，其切换后主体估计为 (D(M+1)+2(D+D_2)+LS=11544) 乘/点。一次 SVD 采用旧诊断的 **100 万乘 convention**，属于统一近似账本，并非精确实测 FLOP。

| 臂 | 切换后主体乘/点 | 全程平均主体乘/点 | 计入的一次乘法 | 摊销后乘/点 |
|---|---:|---:|---:|---:|
| R4 | 19,132 | 19,132.0 | 0 | 19,132.000 |
| A | 15,822 | 15,987.5 | 1,002,090 | 15,990.005 |
| B | 15,822 | 15,987.5 | 2,090 | 15,987.505 |
| C | 19,132 | 19,132.0 | 1,002,180 | 19,134.505 |
| D | 15,822 | 15,987.5 | 1,002,090 | 15,990.005 |
| F | 11,544 | 11,923.4 | 1,002,090 | 11,925.905 |

一次账本包含 R4 权重形成的 2,000 次乘法；A/C/D/F 再加 SVD convention 和因子奇异值平方根缩放的 (R(25+20)) 次乘法；B 再加随机因子缩放 90 次乘法。**未计**排序的比较/搬移、每点两次 500 元 `z/q` gather、随机数生成、内存访问与状态复制、候选训练和在线门控。500 个排列索引用 `uint16` 保存需约 **1,000 字节**，若用 32 位索引则约 2,000 字节；也不能把更新/排序视作免费容量。主体成本是假定切换后停止教师 R4 的反事实账本，实际并排研究脚本为了配对评分同时运行多个臂。

## 复现与核查

从仓库根目录执行（Python 环境需有 NumPy）：

```powershell
python -B experiments_v13/diagnostics/warmstart_controls/warmstart_controls.py --runs 0
python -B experiments_v13/diagnostics/warmstart_controls/warmstart_controls.py
python -B experiments_v13/diagnostics/warmstart_controls/switch_transient.py
python -B experiments_v13/diagnostics/warmstart_controls/verify_outputs.py
python -B experiments_v13/diagnostics/warmstart_controls/summarize_results.py
```

主脚本按来源 SHA 与初始化文件 SHA 使用缓存；需强制逐样本重跑时加 `--refresh`。代码逐样本计算 RFF、filtered-x 特征、实际 FIR 及 ANR，不以保存的输出当控制器输出。独立校验覆盖 10 条 run、40 个末窗，保存的 SVD 重构误差差异为 0，连续 R4 相对原保存末窗的最大 ANR 偏差 (8.15\times10^{-7}) dB；排列前后 full500 的瞬时输出不变误差最大低于 (10^{-12})，FIR 状态继承误差为 0，切换初始化文件与短时重放一致。逐 run 来源散列、初始化、成本与段结果保存在 `E2_run00.json` 等文件及配对 NPZ 中。

这是已知 20k 切换时点、已运行 R4 教师的开发集反事实诊断。B 仍承担 R4 前缀与排序，因而不能单独剔除 R4 预训练的作用；也没有预先冻结同一排列后从头训练 R2/R3 的纯低秩对照、在线门控或候选成本。E2/E3 run00–04 不是独立确认集；这些机制证据只支持继续设计因果选择规则，不构成可部署的自适应项数收益或论文性能结论。
